## Provenance fields

Every trained result contains a `release_config_sha256` or
`release_config_sha256s`. The checksum is computed from the canonical,
seed-specific resolved YAML generated by `configs/main/experiments.yaml` at
code revision `50779c6`. This identifies the public reproduction configuration;
it is separate from an artifact checksum generated on an experiment server.

`artifact_sha256` is retained when the shared experiment ledger contains it.
A blank artifact checksum means it was unavailable in the shared ledger; it
does not mean that verification succeeded. Server paths are intentionally not
published.

The official split is evaluated only after checkpoint selection on the
train-derived development split. OPT-13B classification uses the complete
official validation split. SQuAD uses the fixed 1,000-example official subset
and reports F1 and EM. Qwen3-0.6B MultiRC uses all 4,848 answer rows grouped
into 953 questions and reports F1a and EM, with answer accuracy retained as a
supplementary metric.

## Known provenance limits

The OPT-13B aggregate table contains 41 metrics recomputed from committed
three-seed official values. Eight historical aggregate rows—MeZO and AIM-ZO on
RTE, BoolQ, SST-2, and WiC—lack their original per-seed payloads in the shared
experiment repository. They are explicitly marked
`historical_aggregate_without_seed_payload` and are absent from
`official-by-seed.csv`. Their mean and standard deviation are retained as the
circulated paper values without claiming a verified seed count.

Qwen3-0.6B MultiRC F1a/EM are available as five-seed aggregates. The shared
ledger contains per-seed answer accuracy but not the five individual grouped
F1a/EM payloads, so those aggregate rows are marked
`aggregate_only_grouped_metric`.

OPT-13B MeZO SQuAD uses the table's uniform full-parameter generation-CE
protocol. It is not the original MeZO prefix-tuning protocol and is labeled by
its distinct protocol ID.

## Record format

| Field | Meaning |
| --- | --- |
| `protocol_id` | Immutable experiment/evaluation protocol identifier |
| `evaluation_scope` | Full official split or the documented fixed subset |
| `release_config_sha256` | Canonical public resolved-config checksum |
| `release_code_revision` | Public code revision containing that protocol |
| `artifact_sha256` | Original evaluation artifact checksum when available |
| `provenance_status` | Per-seed verified, historical aggregate, or aggregate-only grouped metric |

A blank value denotes unavailable information, never a numerical zero.
